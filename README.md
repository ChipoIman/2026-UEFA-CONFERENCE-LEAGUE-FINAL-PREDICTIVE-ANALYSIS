# 2026-UEFA-CONFERENCE-LEAGUE-FINAL-PREDICTIVE-ANALYSIS
This is a predictive analysis of Crystal Palace F.C's win probability against Rayo Vallecano in the 2026 Uefa conference league final  using 6 datasets from 3 leagues(The English Premier League, La Liga and the UEFA conference league). Compared 4 machine learning models with 68.8% test accuracy.  Python, Pandas, scikit-learn, W&amp;B
